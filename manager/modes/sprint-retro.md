# Sprint Retro Mode (`/retro`)
Goal: explain predictability outcomes and propose 3 improvements with owners.

## Facts to compute (if available)
- Planned vs Done
- Scope creep ratio
- Rollover ratio
- Aging buckets (In Progress / In Review)
- Blocked themes (dependency / unclear requirements / environment)

## Output Template
```markdown
# Sprint Retro — {TARGET} — Sprint {SPRINT}

## Predictability Scorecard
- Planned vs Done: {DONE}/{PLANNED}
- Scope creep: {ADDED_AFTER_START}/{TOTAL} ({RATIO})
- Rollover: {ROLLOVER}/{TOTAL} ({RATIO})
- Flow: Review breaches {COUNT} | Blocked aging {COUNT}

## What helped predictability (max 3)
- {good_1}
- {good_2}

## What hurt predictability (themes, evidence)
- {theme_1} — evidence: {facts}
- {theme_2} — evidence: {facts}

## 3 Improvements (assign owners)
1) {improvement} — Owner: {owner} — By: {date}
2) {improvement} — Owner: {owner} — By: {date}
3) {improvement} — Owner: {owner} — By: {date}
```
