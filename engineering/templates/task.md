# Task Templates

> **DEPRECATED**: This file has been split into focused templates.

## Use the Appropriate Template

| Task Type | Template | Use For |
|-----------|----------|---------|
| **Backend** | [`task-backend.md`](./task-backend.md) | Database, Service, API layers |
| **Frontend** | [`task-frontend.md`](./task-frontend.md) | Frontend components, State management |

---

## Template Selection Guide

**Backend Tasks** (use `task-backend.md`):
- Database migrations and entities
- Service layer business logic
- API controllers and endpoints
- Integration with external services

**Frontend Tasks** (use `task-frontend.md`):
- React components
- Redux/state management
- UI pages and layouts
- Form handling and validation

---

> **For TaskPlanning mode**: The agent automatically selects the correct template based on the task's Layer field (Database/Service/API → backend, Frontend/State → frontend).
