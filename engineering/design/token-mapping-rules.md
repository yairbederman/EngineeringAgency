# Token Mapping Rules

> **Purpose**: Algorithmic rules to convert Figma design values to project design tokens.

---

## 1. Token Resolution Priority

**ALWAYS resolve tokens in this order**:

1. **Figma Variables** (highest priority)
   - Source: `mcp1_get_variable_defs` response
   - If element has a linked variable (e.g., `color/primary/500`), use directly
   - See: `figma-automation.md` Step 2G

2. **Figma Style Name** (if available)
   - If Figma element has a linked style (e.g., `Primary/500`), match to project token by name
   
3. **Project Design Tokens**
   - Read from: `${PROJECT_ROOT}/.ai-instructions/analysis/design-tokens.json`
   - Contains: Project's actual colors, spacing, typography extracted during codebase analysis
   
4. **Algorithmic Matching** (fallback)
   - Use algorithms below when no exact match exists
   - Always annotate with `⚠️ (closest match)`

---

## 2. Color Matching Algorithm

### 2.1 RGB Distance Formula

```
distance = sqrt((r1-r2)² + (g1-g2)² + (b1-b2)²)
```

### 2.2 Process

1. Convert Figma color (0-1 floats) to RGB (0-255):
   ```
   R = round(color.r × 255)
   G = round(color.g × 255)
   B = round(color.b × 255)
   ```

2. Compare against all colors in `design-tokens.json` → `colors` object

3. Select color with **minimum distance**

4. **Threshold**: If distance > 30, add annotation: `⚠️ (approximate)`

### 2.3 Output Format

```markdown
| Category | Figma Value | Project Token |
|----------|-------------|---------------|
| Background | #F0F1F3 | bg-gray-100 |
| Background | #F0F1F3 | bg-gray-100 ⚠️ (closest, distance: 42) |
```

## 3. Spacing Matching Algorithm

### 3.1 Process

1. Read spacing scale from `design-tokens.json` → `spacing` object
2. Find value in scale closest to Figma pixel value
3. Round to nearest scale value

### 3.2 Rounding Rules

| Condition | Action |
|-----------|--------|
| Exact match exists | Use exact token |
| Within ±1px of scale value | Use scale value, no annotation |
| >1px from nearest | Use nearest + annotate: `⚠️ (rounded from Xpx)` |
| >50% between two values | Flag for design review |

### 3.3 Context Prefixes

Apply appropriate prefix based on CSS property:

| Property | Prefix | Example |
|----------|--------|---------|
| gap | `gap-` | `gap-4` |
| padding | `p-`, `px-`, `py-`, `pt-`, etc. | `p-6` |
| margin | `m-`, `mx-`, `my-`, `mt-`, etc. | `mt-4` |
| width | `w-` | `w-64` |
| height | `h-` | `h-12` |

---

## 4. Typography Matching Algorithm

### 4.1 Font Size

1. Read scale from `design-tokens.json` → `fontSize` object
2. Match to closest scale value
3. If >1px difference, annotate

### 4.2 Font Weight

1. Read weights from `design-tokens.json` → `fontWeight` object
2. Match numeric weight (100-900) to named token

### 4.3 Line Height

| Figma Value | Mapping Logic |
|-------------|---------------|
| `AUTO` | `leading-normal` |
| Percentage (e.g., 150%) | Match to relative token (e.g., `leading-normal` = 1.5) |
| Fixed pixels | Use arbitrary value: `leading-[24px]` |

---

## 5. Border Radius Matching Algorithm

1. Read scale from `design-tokens.json` → `borderRadius` object
2. Match to closest scale value
3. If different per corner, use per-corner tokens

---

## 6. Shadow Matching Algorithm

1. Read shadows from `design-tokens.json` → `boxShadow` object
2. Match primarily by **blur radius**, then y-offset
3. If no close match, use arbitrary value or flag

---

## 7. Layout Mapping Rules

### 7.1 Figma to CSS (Static Rules)

| Figma Layout Mode | CSS |
|-------------------|-----|
| `HORIZONTAL` | `flex-row` |
| `VERTICAL` | `flex-col` |
| `NONE` | (absolute positioning) |

| Figma Primary Axis | CSS Class |
|--------------------|-----------|
| `MIN` | `justify-start` |
| `CENTER` | `justify-center` |
| `MAX` | `justify-end` |
| `SPACE_BETWEEN` | `justify-between` |

| Figma Counter Axis | CSS Class |
|--------------------|-----------|
| `MIN` | `items-start` |
| `CENTER` | `items-center` |
| `MAX` | `items-end` |
| `STRETCH` | `items-stretch` |
| `BASELINE` | `items-baseline` |

| Figma Sizing | CSS Class |
|--------------|-----------|
| `HUG` | (auto, no class) |
| `FILL` | `flex-1` or `w-full` / `h-full` |
| `FIXED` | `w-[Xpx]` / `h-[Xpx]` |

---

## 8. Fallback Annotation Format

When no exact match exists:

```markdown
| Category | Figma Value | Project Token |
|----------|-------------|---------------|
| Background | #F0F1F3 | bg-gray-100 ⚠️ (closest match) |
| Spacing | 13px | gap-3 ⚠️ (rounded from 13px) |
| Font Size | 15px | text-base ⚠️ (rounded from 15px) |
```

### 8.1 Threshold for Flagging

| Category | Threshold | Annotation |
|----------|-----------|------------|
| Color | RGB distance > 30 | `⚠️ (approximate)` |
| Spacing | > 2px difference | `⚠️ (rounded from Xpx)` |
| Font Size | > 1px difference | `⚠️ (rounded from Xpx)` |
| Border Radius | > 2px difference | `⚠️ (rounded from Xpx)` |
