# System Architecture Agent Configuration

> **Purpose**: Single source of truth for system architecture agent paths and project registry.
> Update `SYSTEM_ARCH_ROOT` and project list when migrating or adding projects.

---

## Agent Paths

| Variable | Value | Description |
|----------|-------|-------------|
| `SYSTEM_ARCH_ROOT` | `./system-architecture` | Base path for agent files (relative to `global_workflows` root) |

### Phase Files (relative to SYSTEM_ARCH_ROOT)

| Phase | File | Output |
|-------|------|--------|
| Phase 1: Project Inventory | `_phase-1-project-inventory.md` | `analysis/project-inventory.json` |
| Phase 2: Service Topology | `_phase-2-service-topology.md` | `analysis/service-topology.json` |
| Phase 3: Cross-Service APIs | `_phase-3-cross-service-apis.md` | `analysis/cross-service-apis.json` |
| Phase 4: Domain Model | `_phase-4-domain-model.md` | `analysis/unified-domain-model.json` |
| Phase 5: Generate System Doc | `_phase-5-generate-system-doc.md` | `system-architecture.md`, `deep-dive/*` |

---

## Output Paths

| Variable | Path | Description |
|----------|------|-------------|
| `${OUTPUT_ROOT}` | `${WORKSPACE_ROOT}/system-architecture` | Root for all generated system documentation |
| `${ANALYSIS_DIR}` | `${OUTPUT_ROOT}/analysis/` | JSON analysis files |
| `${DEEP_DIVE_DIR}` | `${OUTPUT_ROOT}/deep-dive/` | Detailed documentation |

> **Note**: `${WORKSPACE_ROOT}` is defined in [shared/projects.md](../shared/projects.md).

> [!IMPORTANT]
> **Path Synchronization Required**  
> The `OUTPUT_ROOT` path **MUST** match `${SYSTEM_ARCH_ROOT}` in `/engineering-agent`'s configuration (`engineering/configuration.md`).  
> When updating this path, also update the corresponding path in engineering configuration.

---

## Project Registry

> **📁 Source**: [shared/projects.md](../shared/projects.md) – Single source of truth for all agents.
>
> This agent will scan all projects listed in the shared projects file.

### Per-Project Required Files

Each project MUST have these files (generated by `/map-codebase-agent`):

| File | Path | Required |
|------|------|----------|
| AI Instructions Root | `.ai-instructions/` | ✅ |
| Copilot Instructions | `.ai-instructions/copilot-instructions.md` | ✅ |
| Entity Contracts | `.ai-instructions/analysis/entity-contracts.json` | ✅ |
| API Contracts | `.ai-instructions/analysis/api-contracts.json` | ✅ |
| File Categorization | `.ai-instructions/analysis/file-categorization.json` | Optional |

---

## Adding New Projects

1. Add a row to the **Project Registry** table above
2. Run `/map-codebase-agent` on the new project to generate AI instructions
3. Re-run `/system-architecture-agent` to update system documentation

---

## Installation

After cloning, `SYSTEM_ARCH_ROOT` uses relative paths (`./system-architecture`) by default. Update `OUTPUT_ROOT` if your project workspace is in a different location.
